Kheprx.BaseBackend — Project Libraries

All NuGet packages used in the solution, their versions, and what they do.

Central Package Management (CPM): all versions live in Directory.Packages.props; individual projects reference packages without specifying a version. To upgrade a dependency, change the version in one place.
Layers: DomainApplication InfrastructureContracts Host / ApiSharedKernel

How CPM works

Two files work together. Directory.Packages.props declares every version once. Each .csproj references packages without a version attribute.

Directory.Packages.props — the version registry:

<!-- Directory.Packages.props -->
<Project>
  <PropertyGroup>
    <ManagePackageVersionsCentrally>true</ManagePackageVersionsCentrally>
  </PropertyGroup>
  <ItemGroup>
    <!-- Runtime -->
    <PackageVersion Include="Microsoft.EntityFrameworkCore"                      Version="10.0.0" />
    <PackageVersion Include="Microsoft.EntityFrameworkCore.Design"               Version="10.0.0" />
    <PackageVersion Include="Npgsql.EntityFrameworkCore.PostgreSQL"              Version="10.0.0" />
    <PackageVersion Include="System.Security.Cryptography.Xml"                   Version="10.0.8"  />
    <PackageVersion Include="Microsoft.Extensions.DependencyInjection.Abstractions" Version="10.0.0" />
    <PackageVersion Include="Microsoft.Extensions.Configuration.Abstractions"      Version="10.0.0" />
    <PackageVersion Include="FluentValidation"                                    Version="11.11.0" />
    <PackageVersion Include="FluentValidation.DependencyInjectionExtensions"        Version="11.11.0" />
    <PackageVersion Include="Riok.Mapperly"                                       Version="4.3.1"   />
    <PackageVersion Include="Serilog.AspNetCore"                                   Version="9.0.0"   />
    <PackageVersion Include="Swashbuckle.AspNetCore"                               Version="7.2.0"   />
    <!-- Test -->
    <PackageVersion Include="Microsoft.NET.Test.Sdk"          Version="17.12.0" />
    <PackageVersion Include="xunit"                          Version="2.9.2"   />
    <PackageVersion Include="xunit.runner.visualstudio"      Version="2.8.2"   />
    <PackageVersion Include="Moq"                            Version="4.20.72" />
    <PackageVersion Include="NetArchTest.Rules"              Version="1.3.2"   />
  </ItemGroup>
</Project>

A project .csproj — no versions, just names:

<!-- e.g. Kheprx.BaseBackend.Catalog.Infrastructure.csproj -->
<Project Sdk="Microsoft.NET.Sdk">
  <ItemGroup>
    <!-- Version is resolved from Directory.Packages.props -->
    <PackageReference Include="Microsoft.EntityFrameworkCore"         />
    <PackageReference Include="Npgsql.EntityFrameworkCore.PostgreSQL"  />
    <PackageReference Include="FluentValidation"                      />
  </ItemGroup>
</Project>

Directory.Build.props — shared MSBuild defaults (inherited by every project, no version pins here):

<Project>
  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
    <LangVersion>latest</LangVersion>
    <TreatWarningsAsErrors>true</TreatWarningsAsErrors>
  </PropertyGroup>
</Project>

Runtime packages

Packages that ship in the compiled output and are used at application run-time.

Package Version Role Used for
Microsoft.EntityFrameworkCore 10.0.0 Infrastructure ORM core — DbContext, entity tracking, LINQ queries, migrations.
Npgsql.EntityFrameworkCore.PostgreSQL 10.0.0 Infrastructure PostgreSQL provider for EF Core — translates LINQ to SQL and manages the Npgsql connection.
FluentValidation 11.11.0 Application Declarative, chainable validation rules for command/request DTOs.
FluentValidation.DependencyInjectionExtensions 11.11.0 Host / Api Registers all validators from an assembly into the DI container with AddValidatorsFromAssembly.
Riok.Mapperly 4.3.1 Application Source-generated object mapper — zero-reflection mapping between domain entities and DTOs at compile time.
Serilog.AspNetCore 9.0.0 Host / Api Structured logging integration for ASP.NET Core — replaces the default logger with Serilog sinks.
Swashbuckle.AspNetCore 7.2.0 Host / Api Generates an OpenAPI (Swagger) specification from controller metadata and serves the Swagger UI.
System.Security.Cryptography.Xml 10.0.8 Infrastructure Security pin — pinned to patch a known CVE in the transitive dependency pulled in by Npgsql; not directly referenced in application code.

Test packages

Packages referenced only by test projects — not included in the production output.

Package Version Role Used for
Microsoft.NET.Test.Sdk 17.12.0 Test runner MSBuild targets and test host required by dotnet test to discover and run tests.
xunit 2.9.2 Test framework Test class and assertion framework — [Fact], [Theory], Assert.*.
xunit.runner.visualstudio 2.8.2 Test adapter VSTest adapter that lets Visual Studio and the dotnet CLI discover xUnit tests.
Moq 4.20.72 Mocking Creates mock implementations of interfaces (e.g. IProductRepository) for unit testing service behaviour in isolation.
NetArchTest.Rules 1.3.2 Architecture tests Fluent API for asserting dependency rules in Kheprx.BaseBackend.ArchitectureTests — ensures no layer violates the dependency graph.
