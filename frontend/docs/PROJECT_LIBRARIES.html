Project libraries

What each dependency is for and why it's here. Versions reflect package.json.

Snapshot: versions below reflect the current package.json (Angular ^20.3.0) and may change as you update.

Runtime dependencies (dependencies)

@angular/core

^20.3.0

The framework: components, dependency injection (inject, InjectionToken), and signals.

@angular/common

^20.3.0

Common directives/pipes and HttpClient (provideHttpClient) — wrapped by core/network/api/http-client.ts.

@angular/compiler

^20.3.0

The Angular template compiler. Required at runtime in JIT mode and as a peer dependency; the CLI/build uses it during AOT compilation to turn templates into optimised JavaScript.

@angular/router

^20.3.0

Client-side routing. Provides provideRouter, lazy loadComponent for feature routes, and <router-outlet> used in the root App shell.

@angular/forms

^20.3.0

Used by features/auth/presentation/pages/change-password/change-password.page.ts via FormsModule (ngModel); other forms use signal-bound input handlers.

@angular/platform-browser

^20.3.0

Browser bootstrapping. Provides bootstrapApplication (called in src/main.ts) and the DOM-renderer that backs component views.

@angular/animations

^20.3.0

provideAnimations() is registered in app.config.ts (enables Angular's animation system); no current feature defines animation triggers — UI transitions are CSS-based.

rxjs

~7.8.0

Used internally by http-client.ts (timeout, retry, timer); the Observable is adapted to a Promise via an explicit new Promise(...).subscribe(...) at the boundary so the rest of the app stays framework-light.

@lucide/angular

^1.22.0

Crisp, tree-shakeable SVG icon set. Standalone, signal-based directives — import the icon you need (e.g. LucideHome) and apply it on an <svg>: <svg lucideHome [size]="20">. Only the icons you import are bundled. See Styling for usage.

tslib

^2.3.0

TypeScript runtime helper library. The TypeScript compiler emits import … from 'tslib' instead of inlining helpers (e.g. __awaiter, __extends), keeping bundle size down.

zone.js

~0.15.0

Angular's change-detection trigger. Patches browser async APIs (timers, XHR, Promises) so Angular knows when to re-render. Configured as a build polyfill in angular.json (polyfills: ['zone.js']); change detection is set up via provideZoneChangeDetection() in app.config.ts.

Styling toolchain

tailwindcss

^3.4.17

Utility-first CSS framework. Its theme is mapped to the SCSS CSS-variable tokens in tailwind.config.js so classes like text-primary resolve to var(--color-primary) — the same value the rest of the stylesheet uses directly. One palette, no duplication.

postcss

^8.5.16

CSS transformation pipeline. Angular's build runs PostCSS automatically; Tailwind and autoprefixer are registered as PostCSS plugins in postcss.config.js.

autoprefixer

^10.5.2

PostCSS plugin that adds vendor prefixes for cross-browser compatibility. Runs as part of the PostCSS pipeline alongside Tailwind.

Dev dependencies (devDependencies)

@angular/cli

^20.3.26

The ng command-line tool: ng serve, ng build, ng generate. Orchestrates the build pipeline and dev server.

@angular/build

^20.3.26

The official Angular application builder (Vite + esbuild). Consumed by the CLI to compile, bundle, and optimise the app for development and production.

@angular/compiler-cli

^20.3.0

The Angular AOT compiler (ngc). Runs ahead-of-time template compilation during the build step and powers language-service type checking in editors.

typescript

~5.9.2

The TypeScript language compiler. All source files are .ts; TypeScript enforces strict typing at build time and is consumed by both @angular/compiler-cli and Jest.

jest

^30.4.2

The test runner invoked by npm test. Replaces Karma/Jasmine entirely; runs unit tests in a jsdom environment and produces coverage reports.

jest-preset-angular

^17.0.0

Jest preset that adds Angular-specific transforms (template compilation, module resolution). Configured in jest.config.ts via preset: 'jest-preset-angular'.

jest-environment-jsdom

^30.4.1

A DOM simulation environment for Jest. Provides document, window, and related browser globals so Angular component tests can render without a real browser.

@types/jest

^30.0.0

TypeScript type declarations for Jest globals (describe, it, expect, etc.). Allows test files to be type-checked without explicit imports when @jest/globals is not used.

@jest/globals

^30.4.1

Provides explicit ESM-compatible imports of Jest globals (import { describe, it, expect } from '@jest/globals'), avoiding implicit global pollution in strict TypeScript setups.

Deliberately NOT included

No global state library (NgRx, etc.) — local signals suffice (YAGNI).

No extra HTTP client — Angular HttpClient, wrapped for the Promise + Result contract.

No Karma/Jasmine — testing is Jest-only via jest-preset-angular.
