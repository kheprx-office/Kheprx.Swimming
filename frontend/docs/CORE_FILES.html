Domain primitives

Result<T>

core/domain/result/result.tscore

The uniform success/failure value every use case returns. Callers switch on ok instead of writing try/catch.

export type Result<T> =
  | { ok: true; data: T }
  | { ok: false; error: AppError };

export const ok   = <T>(data: T): Result<T>      => ({ ok: true,  data });
export const fail = (error: AppError): Result<never> => ({ ok: false, error });

AppError

core/domain/errors/app-error.tscore

A typed error carrying the failure kind, optional HTTP status, and optional backend error code. The seven-value union drives the error-handling table in every view. See Error Handling for details on each kind.

export type AppErrorKind =
  | 'network' | 'http' | 'validation'
  | 'storage' | 'crypto' | 'auth' | 'unknown';

export class AppError extends Error {
  readonly kind:    AppErrorKind;
  readonly status?: number;
  readonly code?:   string;

  constructor(message: string, kind: AppErrorKind, status?: number, code?: string) {
    super(message);
    this.name = 'AppError';
    this.kind = kind; this.status = status; this.code = code;
  }
}

UseCase<I, O>

core/domain/usecase/use-case.tscore

Abstract base every use case extends. Subclasses implement only the happy path in execute(); run() owns error handling once, so no use case repeats the same try/catch.

export abstract class UseCase<I, O> {
  // happy path only — throw an AppError to signal failure
  protected abstract execute(input: I): Promise<O>;

  async run(input: I): Promise<Result<O>> {
    try {
      return ok(await this.execute(input));
    } catch (e) {
      const error =
        e instanceof AppError ? e : new AppError('Unexpected error', 'unknown');
      return fail(error);
    }
  }
}

UserRole / ROLE_LABELS

core/domain/roles/core

Shared kernel for role identity used by auth, user-management, and layout. The Kheprx.Electric role set is admin, manager, moqawel, and worker. UserRole is the discriminated union of valid role strings; ROLE_LABELS is a display-label map keyed by role. Both are imported wherever role checks or labels are needed — DTOs use them for validation, models use them for typing.

HttpClientService

core/network/api/http-client.tscore

A typed wrapper over Angular HttpClient with five verbs (get/post/put/patch/delete). Returns a Promise<T> and maps failures to AppError via toAppError. Transport failures (status 0, timeout) are retried with exponential backoff; 4xx/5xx errors are never retried. Repositories inject this directly and return the raw DTO envelope; the use case owns validation and mapping. See HTTP Client for full documentation.

export interface HttpRequestOptions {
  body?: unknown; headers?: Record<string, string>;
  params?: Record<string, string | number | boolean>;
}

@Injectable({ providedIn: 'root' })
export class HttpClientService {
  get<T>(path: string, opts?: HttpRequestOptions): Promise<T>;
  post<T>(path: string, opts?: HttpRequestOptions): Promise<T>;
  put<T>(path: string, opts?: HttpRequestOptions): Promise<T>;
  patch<T>(path: string, opts?: HttpRequestOptions): Promise<T>;
  delete<T>(path: string, opts?: HttpRequestOptions): Promise<T>;
}

toAppError / http-error

core/network/api/http-error.tscore

Maps an HttpErrorResponse (or transport error) to a typed AppError. Status 0 → 'network'; 401 → 'auth'; other non-2xx → 'http' (carries status + backend code if the body is a JSON object with a code field).

The auth interceptor (Bearer token + 401→refresh→retry) lives at features/auth/data/auth.interceptor.ts, not in core/network. It is registered via provideHttpClient(withInterceptors([authInterceptor])) in app.config.ts.

Storage

KeyValueStore

core/datasource/keyvalue/key-value.store.tscore

Typed wrapper over localStorage that owns serialization and error mapping once. Corruption is intentionally asymmetric: a malformed object throws AppError('storage'), while a malformed primitive falls back to the caller's default.

@Injectable({ providedIn: 'root' })
export class KeyValueStore {
  setString(key: string, value: string): Promise<void> { ... }
  getString(key: string): Promise<string | null> { ... }

  setObject<T>(key: string, value: T): Promise<void> { ... }
  async getObject<T>(key: string): Promise<T | null> {
    const raw = await this.getString(key);
    if (raw === null) return null;
    try {
      return JSON.parse(raw) as T;
    } catch (e) {
      // corrupt object → throw, not silently default
      throw new AppError('Failed to load data', 'storage');
    }
  }
}

// Shared non-DI singleton (parity with mobile). Prefer DI in app code.
export const keyValueStore = new KeyValueStore();

Crypto

CryptoService

core/crypto/crypto.service.tscore

AES-256-GCM encrypt/decrypt of arbitrary strings. The CryptoKey comes from an injected KeyProvider (IndexedDB in production); the AES work goes through an injected WebCryptoLike. Both seams keep this class testable on Node's webcrypto. Output format: Base64( iv(12 bytes) ‖ ciphertext+tag ).

export class CryptoService {
  constructor(
    private readonly keys: KeyProvider,
    private readonly crypto: WebCryptoLike,
  ) {}

  async encrypt(plain: string): Promise<string> {
    const key = await this.keys.getOrCreateKey();
    const iv  = this.crypto.getRandomValues(new Uint8Array(12));
    const cipherBuf = await this.crypto.subtle.encrypt(
      { name: 'AES-GCM', iv }, key, new TextEncoder().encode(plain),
    );
    const ciphertext = new Uint8Array(cipherBuf);
    const out = new Uint8Array(iv.length + ciphertext.length);
    out.set(iv, 0);
    out.set(ciphertext, iv.length);
    return toBase64(out);
  }

  async decrypt(blob: string): Promise<string> { ... }
}

WebCryptoLike / KeyProvider

core/crypto/types.tscore

Seam interfaces that let CryptoService run without the real browser globals in tests. Production wires window.crypto and an IndexedDB-backed key provider; tests inject Node's webcrypto and an in-memory provider.

export interface WebCryptoLike {
  getRandomValues<T extends ArrayBufferView>(array: T): T;
  subtle: {
    encrypt(
      algorithm: { name: 'AES-GCM'; iv: BufferSource },
      key: CryptoKey,
      data: BufferSource,
    ): Promise<ArrayBuffer>;
    decrypt(
      algorithm: { name: 'AES-GCM'; iv: BufferSource },
      key: CryptoKey,
      data: BufferSource,
    ): Promise<ArrayBuffer>;
  };
}

export interface KeyProvider {
  getOrCreateKey(): Promise<CryptoKey>;
}

webCryptoKeyStore

core/crypto/web-crypto-key-store.tscore

The production KeyProvider. Generates a non-extractable AES-256-GCM CryptoKey and persists it in IndexedDB (structured clone supports CryptoKey). Raw key bytes never leave the browser.

export const webCryptoKeyStore: KeyProvider = {
  async getOrCreateKey(): Promise<CryptoKey> {
    if (cached) return cached;
    const db       = await openDb();        // IndexedDB 'base-frontend-crypto'
    const existing = await idbGet(db, KEY_ID);
    if (existing) { cached = existing; return cached; }

    const key = await crypto.subtle.generateKey(
      { name: 'AES-GCM', length: 256 },
      false,                                // non-extractable
      ['encrypt', 'decrypt'],
    );
    await idbPut(db, KEY_ID, key);
    cached = key;
    return cached;
  },
};

cryptoService (production composition)

core/crypto/index.tscore

UI

NotificationService

core/ui/notification.service.tscore

App-wide toast/snackbar state — the web equivalent of the mobile Alert.alert. Pages call success() or error(); NotificationHostComponent renders the current signal.

export type Notification = { kind: 'success' | 'error'; message: string };

@Injectable({ providedIn: 'root' })
export class NotificationService {
  private readonly _current = signal<Notification | null>(null);
  readonly current = this._current.asReadonly();

  success(message: string): void { this._current.set({ kind: 'success', message }); }
  error(message: string):   void { this._current.set({ kind: 'error',   message }); }
  clear():                  void { this._current.set(null); }
}
