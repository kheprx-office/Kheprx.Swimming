Styling — one palette, three layers

CSS custom-property tokens in theme.scss are the single source of truth. Tailwind utilities and the TypeScript theme object both reference those same variables, so the entire app shares exactly one palette.

Rule: define a colour or spacing value once in theme.scss; reference it everywhere else via var(--...) or a Tailwind utility class. Never hard-code a hex or pixel value in a component.

Design tokens — theme.scss

theme.scss — CSS custom properties

coresrc/app/core/ui/theme/theme.scss

The canonical source of truth for all design tokens. Declared on :root so they are available in every component stylesheet, including those with ViewEncapsulation.Emulated (the Angular default).

// theme.scss
:root {
  --color-primary:    #0a84ff;
  --color-text:       #111;
  --color-muted:      #555;
  --color-error:      #c00;
  --color-border:     #ccc;
  --color-background: #fff;
  --color-on-primary: #fff;

  --space-xs: 4px;  --space-sm: 8px;
  --space-md: 16px; --space-lg: 24px; --space-xl: 32px;

  --radius-sm: 6px; --radius-md: 10px;
}

Use these in component SCSS/CSS as var(--color-primary), var(--space-md), etc. To retheme the app, change the values here only.

Tailwind mapped to tokens — tailwind.config.js

Single-palette Tailwind config

coretailwind.config.js

Tailwind's theme.extend maps every utility scale to the SCSS CSS variables. A class like text-primary resolves to var(--color-primary) at runtime — the same value the SCSS uses directly. There is no separate Tailwind palette.

module.exports = {
  content: ['./src/**/*.{html,ts}'],
  theme: {
    extend: {
      colors: {
        primary:      'var(--color-primary)',
        text:         'var(--color-text)',
        muted:        'var(--color-muted)',
        error:        'var(--color-error)',
        border:       'var(--color-border)',
        background:   'var(--color-background)',
        'on-primary': 'var(--color-on-primary)',
      },
      spacing: {
        xs: 'var(--space-xs)',  sm: 'var(--space-sm)',
        md: 'var(--space-md)',  lg: 'var(--space-lg)', xl: 'var(--space-xl)',
      },
      borderRadius: { sm: 'var(--radius-sm)', md: 'var(--radius-md)' },
    },
  },
};

Tailwind is configured as a PostCSS plugin (postcss.config.js) alongside autoprefixer. Angular's build pipeline runs PostCSS automatically.

Design tokens in TypeScript — theme.ts

theme object

coresrc/app/core/ui/theme/theme.ts

A typed as const object that mirrors the CSS variables for use in component TypeScript (e.g. passing a colour to a canvas or a third-party library that does not accept CSS variables).

export const theme = {
  colors: {
    primary: '#0a84ff', text: '#111', muted: '#555',
    error: '#c00', border: '#ccc', background: '#fff', onPrimary: '#fff',
  },
  spacing: { xs: 4, sm: 8, md: 16, lg: 24, xl: 32 },
  radius:  { sm: 6, md: 10 },
} as const;

These numeric values match the px values in theme.scss. If you change a token in theme.scss, update this object to match.

Icons — @lucide/angular

Lucide{Icon} directives

core@lucide/angular ^1.22.0

Standalone, signal-based icon directives. Import the specific icon (e.g. LucideHome) and apply it as an attribute on an <svg> element.

// In the component:
import { LucideHome } from '@lucide/angular';

@Component({
  imports: [LucideHome],
  template: `<svg lucideHome [size]="20"></svg>`,
})
export class MyComponent {}

Browse available icon names at lucide.dev/icons. Import only the icons your component uses — tree-shaking removes the rest.

See also: Project Libraries for Tailwind/PostCSS version details, and Core Files for the full UI-component API.
